## 2. What I Learned

- Clear-text protocols such as HTTP expose usernames and passwords to anyone who can capture the traffic, which is why encryption (HTTPS/TLS) matters.
- Even when content is encrypted, details like the server name, ports, and TLS version are still visible in a capture.
- Brute-force attacks leave a clear pattern: many repeated attempts from the same source.
- Follow TCP Stream is one of the fastest ways to understand what happened in a conversation.
